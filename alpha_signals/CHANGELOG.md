## [1.0.0] - 2026-03-12

### Added
- ✅ 5 smart contracts deployed on BSC
  - ERC-8183 (Alpha Signals)
  - ERC-8004 (Reputation)
  - ERC-8126 (Risk Scoring)
  - ERC-8021 (Attribution)
  - VestingGateIO
- ✅ Dashboard with real-time BTC price
- ✅ AI signal generator (BTC, ETH, BNB)
- ✅ Win/Loss transparency
- ✅ 9 beta testers onboarded
- ✅ Token LEVE (BEP-20) with 53+ holders

### Changed
- Improved dashboard UI/UX
- Fixed CORS issues for mobile
- Updated contract addresses in frontend

### Fixed
- API proxy configuration (Nginx)
- Error icons in contract list
- Mobile menu visibility

### Technical
- Deployment cost: ~$0.06 USD
- Backend: Node.js + Express
- Frontend: Next.js 14
- AI Engine: Python + Flask
- Database: PostgreSQL
