# Leve IA: ERC-8004 Integration Guide
## Verifiable AI Alpha for the Agentic Economy

This guide provides the technical specification for agents to integrate with the Leve IA Alpha Engine on Base Mainnet.

### Protocol Overview
The ERC-8004 implementation ensures that every prediction generated by an AI agent is hashed and finalized on-chain. This prevents "hallucination-based spending" in autonomous agentic commerce.

### Integration Steps
1. **Query Oracle:** Agents can fetch the latest verified bias from https://coinmarketleve.com/api/v1/alpha
2. **Verify Proof:** Cross-reference the prediction hash with the LeveIAAgent contract on Base (`0x2333cBC71805b47D64C2867Ef66682c7257B5D4f`).
3. **Execute:** Perform USDC/WETH transactions only after on-chain validation.
