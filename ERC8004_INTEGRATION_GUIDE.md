This guide provides the technical specification for agents to integrate with the Leve IA Alpha Engine on **BSC Mainnet**.

### Protocol Overview
The ERC-8004 implementation ensures that every prediction generated by an AI agent is hashed and finalized on-chain. This prevents "hallucination-based spending" in autonomous agentic commerce.

**⚠️ IMPORTANT:** All contracts are deployed on **BSC (Binance Smart Chain)**, NOT on Base or Ethereum.

---

### Integration Steps

1. **Query Oracle:** Agents can fetch the latest verified bias from `https://api.coinmarketleve.com/alpha-prediction`

2. **Verify Proof:** Cross-reference the prediction hash with the Leve IA contracts on BSC.
