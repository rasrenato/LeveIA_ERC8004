## 🤖 AUTOMAÇÃO

### Comandos Disponíveis:

```bash
# Verificar sinais na zona de entrada
node /root/openclaw/trading/automate-concierge.js entry

# Verificar TP1 batidos
node /root/openclaw/trading/automate-concierge.js tp1

# Enviar lembrete de afiliados
node /root/openclaw/trading/automate-concierge.js affiliate

# Executar tudo
node /root/openclaw/trading/automate-concierge.js all
```

### PM2 (Produção):

```bash
# Adicionar ao PM2 (rodar a cada 10 min)
pm2 start /root/openclaw/trading/automate-concierge.js --name "concierge-entry" --cron "*/10 * * * *" -- entry

pm2 start /root/openclaw/trading/automate-concierge.js --name "concierge-tp1" --cron "*/10 * * * *" -- tp1

pm2 start /root/openclaw/trading/automate-concierge.js --name "concierge-affiliate" --cron "0 10 * * 0" -- affiliate
```
