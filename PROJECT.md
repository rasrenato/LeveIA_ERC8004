# Leve IA - Project Vision

**Missão:** Facilitar o uso de cripto para leigos com transparência total via Blockchain.

---

## 🎯 **VISÃO DO PRODUTO**

Leve IA é um ecossistema completo de contratos inteligentes na Binance Smart Chain (BSC) que oferece:

1. **Token Oficial (BEP-20)** - `0x67e463AcC3B35406B0f35C8Ed531da89f9670861`
2. **Pré-venda com Vesting** - Anti-dump, segurança para investidores
3. **Alpha Signals** - Dashboard de sinais de trading validados
4. **Proof of Yield** - Verificação on-chain de resultados
